КВАДРО-БАНЯ — версия 4

Проект специально отформатирован для удобного изучения кода:
- index.html — HTML, каждый блок на отдельных строках;
- style.css — CSS, селекторы и свойства разнесены по строкам;
- script.js — JavaScript с отступами и понятной структурой;
- assets/ — изображения.

Открывайте папку целиком в VS Code. Для просмотра сайта удобно использовать Live Server.
